# Morse-potential-for-diatomic-system-convolution-data
Example of Morse potential model used to describe the interaction between the two nuclei of a diatomic molecule(HBR in our case). 
It improves on the harmonic-oscillator approximation because it includes anharmonicity and dissociation.

The repo contains a nice convolution code that uses Lorentzian and Gaussian to convolve two different specific experimental data with examples.
